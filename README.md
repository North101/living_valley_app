[Flutter Installation Guide](https://docs.flutter.dev/get-started/install)

## Getting Started

Checkout https://github.com/North101/living_valley_data.git
```bash
git checkout https://github.com/North101/living_valley_data.git
```

Create a symlink to living_valley_data
```bash
ln -s /PATH/TO/living_valley_data/output/data.json ./assets/data.json
ln -s /PATH/TO/living_valley_data/output/data ./assets/data
```
Alternatively just copy the contents of `/PATH/TO/living_valley_data/output/` to `./assets/`
